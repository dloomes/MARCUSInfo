**Works with:** NEC and Sharp NEC projectors that support NEC's projector control commands over the network, including the PA-series laser models such as the NP-PA804UL and NP-PA1004UL.

| | |
|---|---|
| **Type** | Vendor adapter |
| **Vendor** | Sharp NEC |
| **Device types** | Projector |
| **Connection** | NEC projector control protocol over TCP (port 7142) |
| **Power on/off from the portal** | Yes |
| **Protocol in the portal** | NEC projector (`nec_projector`) |

## Before you start

1. Connect the projector's LAN port to the network and note its IP address. Control commands use TCP port 7142.
2. So that the projector can be monitored and switched on while in standby, set its **Standby Mode** to **Normal** or **Network Standby**, not a power-saving mode that turns the network off.
3. If **Control ID** is turned on in the projector's menu, set the `control_id` tag to the same number.

## Add the device

1. In the portal, go to **Devices** and select **New device**.
2. Choose the **Collector** that can reach the device, and set **Protocol** to **NEC projector**.
3. Enter the settings below and save. The Collector picks up the new device within seconds.

| Setting | Required | What to enter | Example |
|---|---|---|---|
| **Address** | Yes | Projector IP or hostname. Port 7142 is the NEC control port default; append :port to override. | `192.168.30.60` |
| **Tags → `control_id`** | No | The projector's Control ID (1–254), only if Control ID is turned on in its menu. | `1` |

<Note>
**Tags** are set in the **Tags** section of the device form: select **Add tag**, then enter the name and value, for example `control_id` = `1`.
</Note>

<Note>
**Warming up and cooling down:** the projector accepts no other commands while it powers on or cools down. **Power Status** shows **warming** or **cooling** during that time, and a command sent then fails with a message saying so. **Power On** during cool-down is refused until cooling has finished.
</Note>

<Note>
**Standby:** in standby the projector reports its power state, light-source and filter hours, faults and identity; input, mute and volume readings return when it's switched on.
</Note>

<Note>
**One connection:** the Collector connects only for each poll or command, so a room control system can use the projector's control port in between.
</Note>

<Note>
**Firmware:** NEC's control commands don't report a firmware version, so these projectors don't appear on the **Firmware** page.
</Note>
