**Works with:** Aurora Multimedia DIDO 4x4 HDMI matrix switchers and video wall processors.

| | |
|---|---|
| **Type** | Vendor adapter |
| **Vendor** | Aurora Multimedia |
| **Device types** | Control |
| **Connection** | JSON over TCP (port 6970) |
| **Power on/off from the portal** | No |
| **Protocol in the portal** | Aurora DIDO (`aurora_dido`) |

## Before you start

1. Check the Collector can reach the DIDO on TCP 6970.
2. To recall presets from the portal, save them on the DIDO first (in its web interface). Their names appear in the **Presets** reading.

## Add the device

1. In the portal, go to **Devices** and select **New device**.
2. Choose the **Collector** that can reach the device, and set **Protocol** to **Aurora DIDO**.
3. Enter the settings below and save. The Collector picks up the new device within seconds.

| Setting | Required | What to enter | Example |
|---|---|---|---|
| **Address** | Yes | DIDO IP (port 6970 is implied). | `192.168.10.30` |
| **Poll rate (seconds)** | No | How often to poll. Defaults to 60s. | `60` |

## Commands

Each command is a button on the device page, and can be used in Room Readiness routines.

| Command | Button | Notes |
|---|---|---|
| `route_out1` | Route Out1 | Asks for the input, 1–4. |
| `route_out2` | Route Out2 | Asks for the input, 1–4. |
| `route_out3` | Route Out3 | Asks for the input, 1–4. |
| `route_out4` | Route Out4 | Asks for the input, 1–4. |
| `route_all` | Route All | Asks for the input, 1–4, and shows it on every output. |
| `set_volume` | Set Volume | Asks for the level, 0–100. |
| `mute_linein` | Mute Linein |  |
| `unmute_linein` | Unmute Linein |  |
| `recall_preset` | Recall Preset | Asks for the preset's name, as saved on the device. |
| `lock_buttons` | Lock Buttons |  |
| `unlock_buttons` | Unlock Buttons |  |
| `reboot` | Reboot |  |

<Note>
**Readings:** the input shown on each output (**Out1 Source** to **Out4 Source**), each output's resolution, the audio routing, line-out and line-in volume, whether the front panel is locked, and the saved presets.
</Note>

<Note>
**Commands:** **Route Out1** to **Route Out4** switch one output to an input; **Route All** switches every output. **Set Volume** sets the line-out level. **Recall Preset** applies a saved preset; it takes the DIDO two or three seconds.
</Note>

<Note>
**New firmware:** if a reading shows as **... Reply** with the device's raw answer instead of a value, the firmware answers in a form the Collector doesn't recognise yet. Send the reply to support so it can be added.
</Note>
